# 🍗 مطعم القيصر - نظام إدارة المطاعم

نظام ويب كامل لإدارة مطعم القيصر، يعمل محلياً بدون سيرفر (HTML/CSS/JS فقط).

## 📁 محتويات الملف

```
alqaysar-restaurant/
├── index.html          ← صفحة القائمة (للزبائن)
├── admin.html          ← لوحة التحكم (للمدير)
├── manifest.json       ← إعدادات PWA
├── css/
│   └── style.css       ← تنسيقات الموقع
├── js/
│   ├── app.js          ← منطق القائمة
│   └── admin.js        ← منطق لوحة التحكم
├── images/
│   └── logo.png        ← شعار المطعم
└── README.md           ← هذا الملف
```

## 🚀 التشغيل على Termux

### 1. تثبيت Termux
حمّل Termux من F-Droid (موصى به) أو Google Play.

### 2. تثبيت Python + http.server
```bash
pkg update
pkg install python -y
```

### 3. نقل الملفات
انسخ مجلد `alqaysar-restaurant` إلى جهازك، ثم ادخل إليه:
```bash
cd alqaysar-restaurant
```

### 4. تشغيل السيرفر المحلي
```bash
python -m http.server 8080
```

### 5. فتح الموقع
افتح المتصفح وادخل إلى:
```
http://localhost:8080
```

أو من جهاز آخر على نفس الشبكة:
```
http://<IP-الجهاز>:8080
```

## 🔐 لوحة التحكم

- **الرابط:** `admin.html`

## ⚡ الميزات

| الميزة | الوصف |
|--------|-------|
| ✅ قائمة طعام تفاعلية | تصفح حسب التصنيفات |
| ✅ لوحة تحكم كاملة | إدارة الأصناف والأسعار |
| ✅ عروض خاصة | إضافة/تعديل العروض |
| ✅ تصنيفات مخصصة | إنشاء فئات جديدة |
| ✅ تخصيص الألوان | تغيير ألوان الموقع |
| ✅ إعدادات الموقع | هاتف، عنوان، مواقع تواصل |
| ✅ تصدير/استيراد | نسخ احتياطي JSON |
| ✅ PWA | يعمل كتطبيق على الجوال |
