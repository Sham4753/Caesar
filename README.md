# 👑 مطعم القيصر - التطبيق الملكي

تطبيق ويب متكامل لإدارة مطعم القيصر، مصمم خصيصاً للعمل في **سوريا** مع دعم كامل للإنترنت الضعيف والمقطوع.

## 📁 هيكلية المشروع

```
alqaysar-restaurant/
├── index.html          ← صفحة القائمة والطلبات (للزبائن)
├── admin.html          ← لوحة التحكم الشاملة (للمدير)
├── manifest.json       ← إعدادات PWA (تطبيق ويب تقدمي)
├── sw.js               ← Service Worker (الأوفلاين)
├── README.md           ← دليل التثبيت والتشغيل
├── css/
│   └── style.css       ← التصميم الملكي الفاخر (ذهبي + أسود)
├── js/
│   ├── app.js          ← منطق السلة + الواتساب + التوصيل
│   └── admin.js        ← منطق لوحة التحكم + الأسعار
└── images/
    └── logo.png        ← شعار القيصر
```

## 🚀 التشغيل على Termux

### الخطوة 1: تثبيت Python
```bash
pkg update
pkg install python -y
```

### الخطوة 2: فك الضغط والدخول للمجلد
```bash
cd $HOME
unzip alqaysar-restaurant.zip
cd alqaysar-restaurant
```

### الخطوة 3: تشغيل السيرفر المحلي
```bash
python -m http.server 8080
```

### الخطوة 4: فتح الموقع
افتح متصفحك وادخل إلى:
```
http://localhost:8080
```

### مشاركة الموقع على نفس الشبكة (الواي فاي)
```bash
# احصل على IP الجهاز
ifconfig
# أو
ip addr
```

شارك الرابط مع أي جهاز متصل بنفس الواي فاي:
```
http://192.168.x.x:8080
```

## ✨ الميزات الرئيسية

### 🎨 التصميم الملكي الفاخر
- خلفية داكنة (#121212) مع لمسات ذهبية (#D4AF37)
- تصميم متجاوب 100% للموبايل والتابلت
- شريط تنبيه قابل للتعديل من الأدمن

### 🛒 نظام الطلبات عبر الواتساب
- سلة مشتريات كاملة
- خيار التوصيل للمنزل أو الاستلام من الفرع
- اختيار المنطقة مع حساب كلفة التوصيل تلقائياً (بالليرة السورية)
- تحويل الطلب إلى رسالة واتساب منسقة بالكامل

### 📴 الوضع السوري (Offline First)
- **Service Worker** يحفظ القائمة والصور محلياً
- يعمل القائمة حتى لو انقطعت الكهرباء والإنترنت
- **Lazy Loading** للصور لتقليل استهلاك الإنترنت (2G/3G)
- تثبيت كتطبيق PWA على الشاشة الرئيسية

### ⚙️ لوحة التحكم الكاملة
- إضافة/تعديل/حذف الأصناف والأسعار والصور
- إدارة التصنيفات والعروض الخاصة
- إدارة مناطق التوصيل وكلفتها
- تفعيل/إيقاف خدمة التوصيل
- تعديل نص شريط التنبيه
- تخصيص معلومات المطعم ومواقع التواصل
- تصدير/استيراد النسخ الاحتياطي (JSON)
